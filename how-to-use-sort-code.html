How to Use a Sort Code

A sort code is used when sending or receiving money within the UK. It works together with an account number to ensure payments are routed correctly.

Making a bank transfer

When sending money, you’ll need the recipient’s sort code and account number. These details tell your bank where to send the funds.

Receiving money

If someone is paying you, you’ll provide your sort code along with your account number.

Setting up direct debits

Sort codes are also used when setting up automatic payments such as bills or subscriptions.

Important tip

Always double-check sort codes before sending money to avoid errors.
